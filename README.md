## How it works

`main.py` (Python 3.13, standard library only) copies the committed
`entry.png` to `/output/entry.png`. The image itself is rendered locally by
`render.py` (Pillow, DejaVu fonts) — it is not part of the graded run.

```bash
python3 -S main.py   # writes /output/entry.png, byte-identical every run
```

The image is a 1024×1024 PNG, 195,951 bytes, rendered deterministically
(two runs produce identical bytes).
